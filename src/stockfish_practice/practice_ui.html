Connect your LLM

Run your model locally and return a legal UCI move from choose(session). The session includes FEN, accepted move history, legal moves, side and clocks. The hosted tournament callback has a different contract.

export STOCKFISH_API_URL=http://127.0.0.1:8003
export STOCKFISH_TEAM_TOKEN='your-practice-token'
chess-sdk practice --agent local_agent:choose --colour black --level 5 \
  --white-minutes 10 --black-minutes 10

HTTP API

Use Authorization: Bearer TOKEN and JSON bodies. Create and action IDs must stay unchanged when retrying a lost response.

GET  /v1/profiles
POST /v1/sessions
  {"request_id":"unique-id","colour":"black","level":5,
   "time_control":{"white":600,"black":600,"increment":0},
   "agent":{"model":"my-local-llm","harness":"v1"}}
GET  /v1/sessions/SESSION_ID
POST /v1/sessions/SESSION_ID/actions
  {"action_id":"unique-id","position_version":1,"action":"move","uci":"e7e5"}
  action can also be "resign" or "cancel" (cancel before the first move only).
GET  /v1/sessions/SESSION_ID/pgn
GET  /v1/teams/me/history?limit=50&offset=0

Poll until engine_pending is false, then ask your LLM for the move. Inspect accepted and reason on each reply. A rejected move keeps your clock running. Engine failures mark the attempt invalid. Sessions and history are kept in memory and are lost on server restart; ratings are not implemented. Draw claims are automatic; Armageddon draw odds are tournament advancement rules, while this API records the chess result.
